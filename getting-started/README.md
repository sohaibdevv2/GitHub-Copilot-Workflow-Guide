## Quick Start (5 minutes)

1. **Install**: Add GitHub Copilot extension to VS Code
2. **Authenticate**: Login with your GitHub account
3. **Test**: Type a comment in any code file and let Copilot suggest
4. **Accept**: Press Tab to accept, Esc to reject
5. **Learn**: Follow the guides below
