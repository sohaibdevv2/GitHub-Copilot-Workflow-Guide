# Code Quality with GitHub Copilot

## Maintaining Standards

GitHub Copilot is a powerful tool, but code quality requires intentional practices.

## Key Principles

1. **Always Review** — Review Copilot-generated code like any other code
2. **Test** — Write tests for Copilot-generated functionality
3. **Style** — Enforce consistent style through linting
4. **Performance** — Spot-check for performance issues
5. **Security** — Apply security review to all code

## Quality Checklist

### Before Committing Copilot Code

```javascript
Code Quality Checklist:
□ Functionality works as specified
□ All tests passing (new + existing)
□ TypeScript/linting errors resolved
□ No obvious performance issues
□ Error handling complete
□ No hardcoded values (except constants)
□ Code is readable and maintainable
□ Comments explain "why" not "what"
□ Security requirements met
□ Documentation updated
```

## Establishing Standards

### Create `.eslintrc`

```json
{
  "env": {
    "browser": true,
    "es2021": true,
    "node": true
  },
  "extends": [
    "eslint:recommended",
    "prettier"
  ],
  "rules": {
    "no-console": ["warn", { "allow": ["warn", "error"] }],
    "no-var": "error",
    "prefer-const": "error",
    "eqeqeq": "error"
  }
}
```

### Create `tsconfig.json` (TypeScript)

```json
{
  "compilerOptions": {
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "target": "ES2020",
    "module": "ESNext"
  }
}
```

## Automated Quality Checks

### GitHub Actions Workflow

```yaml
name: Quality Checks

on: [pull_request]

jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Lint code
        run: npm run lint
      
      - name: Type check
        run: npm run typecheck
      
      - name: Run tests
        run: npm test
      
      - name: Check coverage
        run: npm run test:coverage
        
      - name: Security audit
        run: npm audit
```
