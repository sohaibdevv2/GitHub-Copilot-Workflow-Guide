# Team Standards & Best Practices

## Establish Team Policies

### Create .copilotignore

```
# Never send to Copilot
.env
.env.*.local
secrets/
private-keys/
config/prod/
```

### Create CLAUDE.md for Your Project

```markdown
# [Project Name] — Copilot Guidelines

## Overview
[Project description]

## Stack
- Frontend: React + TypeScript
- Backend: Node.js + Express
- Database: PostgreSQL

## Directory Structure
src/
├── components/
├── pages/
├── services/
├── utils/
└── types/

## Copilot Standards

### Code Style
- TypeScript with strict mode
- Use async/await
- 2-space indentation
- No console.log in production

### Naming Conventions
- Functions: camelCase
- Classes: PascalCase
- Constants: UPPER_SNAKE_CASE
- React components: PascalCase
- Hooks: useXxx

### Patterns to Follow
- See src/services/user-service.ts for service pattern
- See src/components/UserCard.tsx for component pattern
- See tests/user.test.ts for test pattern

### NEVER
- Commit without running tests
- Add secrets to any file
- Use Copilot for sensitive auth without review
- Skip code review
```

## Code Review Checklist for Copilot Code

### Before Merge

```javascript
Copilot-Generated Code Checklist:
□ Functionality
  □ Does it solve the stated problem?
  □ All edge cases handled?
  □ Error cases covered?

□ Quality
  □ Follows project style guide?
  □ TypeScript/linting errors resolved?
  □ Tests all passing?

□ Security
  □ No hardcoded secrets?
  □ Input validation present?
  □ SQL injection prevented (if applicable)?
  □ XSS prevention (if applicable)?

□ Performance
  □ No obvious O(n²) algorithms?
  □ Reasonable memory usage?
  □ Database queries optimized?

□ Maintainability
  □ Code is readable?
  □ Functions have single responsibility?
  □ Comments explain "why" not "what"?

□ Testing
  □ Unit tests for core logic?
  □ Edge cases tested?
  □ Integration tests for flows?
```

## Managing Code Quality

### Enforce Quality Gates

```bash
# .husky/pre-commit

# Run tests
npm test

# Run linting
npm run lint

# Check types
npm run typecheck

# Check for secrets
npm run check-secrets
```

### Setup CI/CD Integration

```yaml
# .github/workflows/validate-copilot-code.yml

name: Validate Code

on: [pull_request]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Install dependencies
        run: npm ci
      
      - name: Lint code
        run: npm run lint
      
      - name: Type check
        run: npm run typecheck
      
      - name: Run tests
        run: npm test
      
      - name: Check test coverage
        run: npm run test:coverage
```

## Anti-Patterns to Prevent

### ❌ Blind Acceptance
**Problem**: Team accepts all Copilot suggestions without review
**Solution**: Enforce review checklist, random spot checks, metrics

### ❌ Over-Reliance
**Problem**: Team relies entirely on Copilot, loses core skills
**Solution**: Pair programming, code review, regular training

### ❌ Inconsistent Style
**Problem**: Each team member uses Copilot differently
**Solution**: Establish CLAUDE.md, prompt library, code review

### ❌ Security Incidents
**Problem**: Secrets or vulnerable code committed
**Solution**: Use `.copilotignore`, pre-commit hooks, security review
