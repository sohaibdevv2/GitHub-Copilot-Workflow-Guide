## Key Concepts

- **Context**: Information Copilot uses to generate code
- **Prompts**: How you communicate with Copilot
- **Patterns**: Standard code structures Copilot recognizes
- **Suggestions**: Output from Copilot (can be accepted or rejected)
- **Iteration**: Refining prompts to get better results

---

## Mental Model

Think of GitHub Copilot as:
- **Not**: A replacement for developers
- **But**: A very smart autocomplete that understands code context

It works best when you:
- Provide clear intent
- Maintain good code structure
- Review all suggestions
- Iterate on prompts
